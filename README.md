🌾 HarvestAI – Crop Yield Prediction System
📌 Overview

HarvestAI is a data-driven machine learning project designed to analyze agricultural data and predict crop yield based on key environmental and farming factors. The project leverages data preprocessing, visualization, and predictive modeling to generate insights that can help improve agricultural productivity.

🚀 Features
📊 Exploratory Data Analysis (EDA)
🧹 Data Cleaning & Preprocessing
📉 Statistical Insights & Visualization
🤖 Machine Learning Model for Yield Prediction
📈 Feature Analysis using real-world agricultural data
🗂️ Project Structure
